# LatAm Expansion

LatAm Expansion is a Vintage Story mod that adds Latin American crops, fruits, and ingredients intended to be used by other content mods.

## Installation

Place the mod folder or release archive in your Vintage Story `Mods` directory.

## Development

This repository is intended to track the source files for the mod. Build outputs, temporary files, logs, and generated release archives should not be committed.
